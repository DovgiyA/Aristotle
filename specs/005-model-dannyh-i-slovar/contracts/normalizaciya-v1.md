# Контракт: Классы нормализации версии 1 и их векторы

Нормализованная форма — часть протокола: по ней считаются Отпечатки у всех Групп (DICT-38, фича
021), строгое опознание и автосклейка (фича 012). Правила — DICT-27 … DICT-36; решения — research
R7. Реализация — `packages/protocol/src/normalize/`; векторы ниже лежат в
`packages/protocol/test/vectors/normalizaciya-v1.json`, и контрактный тест прогоняет каждый.
Значения синтетические (принцип VII).

## Общие правила

- Вход — значение как введено (DICT-37); выход — `{ ok: true, value }` или `{ ok: false, reason }`.
- `ok: false` — метка «не нормализуется», Отпечатка нет (DICT-39). Формат типа (§5 приложения)
  проверяется отдельно и до нормализации (research R8).
- Класс неизменяем: другой алгоритм — новое имя класса (`имя-хоста/2`), назначенное типу новой
  версией Словаря Сети (DICT-26).
- Unicode — версия 17.0; таблица NFKC_Casefold закреплена этой версией.
